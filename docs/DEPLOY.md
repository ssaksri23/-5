# 외부 서버 배포 가이드 (도메인 + SSL 포함)

이 문서는 `129.121.127.196` 같은 외부 리눅스 서버에 이 저장소(GNUBoard5 +
스마트비즈 테마)를 배포하고, 새로 구매한 도메인을 연결해 SSL(HTTPS)까지
붙이는 절차입니다.

**중요: 이 스크립트는 Claude가 대신 실행해주는 것이 아니라, 사용자가 직접
그 서버에 SSH로 접속해서 root로 실행하는 스크립트입니다.** 이 저장소 세션은
보안상 임의의 외부 서버에 root로 접속하도록 허용되어 있지 않습니다.

## 준비물

1. 배포할 서버 (예: `129.121.127.196`), root 접속 정보
2. 도메인 1개 (가비아 등에서 연간 1,000원 미만짜리도 충분합니다 — `.xyz`,
   `.shop` 류 프로모션 TLD를 확인해보세요)

## 1단계 — 도메인 구매 + A레코드 연결

1. 가비아(또는 원하는 등록대행사)에서 도메인을 구매합니다.
2. 구매한 도메인의 DNS 관리 화면으로 들어갑니다.
3. **A 레코드**를 추가합니다.
   - 호스트: `@` (루트 도메인으로 접속하고 싶은 경우) 또는 `www` 등 원하는
     서브도메인
   - 값(IP): `129.121.127.196`
   - TTL: 기본값 그대로 두면 됩니다
4. 저장 후 DNS 전파를 기다립니다(보통 몇 분~1시간, 길면 24시간).
5. 아래 명령으로 전파가 끝났는지 확인할 수 있습니다.

   ```bash
   dig +short mysite.example.com
   # 129.121.127.196 이 나오면 완료
   ```

## 2단계 — 서버에서 배포 스크립트 실행

1. 터미널(또는 PuTTY 등)로 서버에 SSH 접속합니다.

   ```bash
   ssh root@129.121.127.196
   ```

2. 이 저장소를 받아옵니다(비공개 저장소이므로 GitHub 로그인/토큰이
   필요할 수 있습니다).

   ```bash
   git clone --branch claude/gnuboard5-sellable-theme \
     https://github.com/ssaksri23/-5.git /opt/smartbiz-gnuboard5
   cd /opt/smartbiz-gnuboard5
   ```

3. 배포 스크립트를 실행합니다. 첫 번째 인자는 연결할 도메인, 두 번째 인자는
   SSL 인증서 만료 알림을 받을 이메일입니다.

   ```bash
   sudo bash scripts/deploy-server.sh mysite.example.com admin@example.com
   ```

   이 스크립트가 하는 일:
   - 서버에서 **비어있는 포트를 자동으로 찾아** (기본 8081부터 확인) 우리
     사이트 컨테이너를 그 포트의 `127.0.0.1`에만 띄웁니다 — 외부에서 그
     포트로 직접 접근할 수 없고, 반드시 도메인을 통해서만 접속됩니다. 서버에
     이미 떠 있는 다른 서비스/포트는 건드리지 않습니다.
   - Docker, Nginx, Certbot이 없으면 설치합니다.
   - `docker compose up -d --build`로 GNUBoard5 + 스마트비즈 테마를 기동합니다.
   - 지정한 도메인 전용 Nginx 설정 파일을 **새로 추가만** 합니다(기존 Nginx
     설정은 건드리지 않습니다).
   - Let's Encrypt로 무료 SSL 인증서를 발급하고 HTTPS로 자동 리다이렉트되게
     설정합니다.

4. 완료되면 `https://mysite.example.com` 으로 접속해 확인합니다.

## 3단계 — 그누보드5 설치 + 테마 적용

1. 처음 배포한 것이라면 `https://mysite.example.com/install/` 로 접속해
   그누보드5 설치 마법사를 진행합니다(DB 정보는 서버의
   `/opt/smartbiz-gnuboard5/.env` 파일에서 확인할 수 있습니다 — 컨테이너
   내부 호스트명은 `db`, 포트는 `3306`입니다).
2. 관리자 로그인 후 **환경설정 → 테마 설정**에서 "스마트비즈" 테마를 선택,
   적용합니다.
3. 관리자 메뉴의 새로 생긴 **"테마 설정"** 탭에서 회사정보를 입력하고,
   **설치 마법사**로 게시판/메뉴를 생성합니다. 원하면 업종별 샘플 데이터도
   함께 적용할 수 있습니다.

## 자주 발생하는 문제

- **도메인 접속이 안 돼요**: `dig +short 도메인` 으로 A레코드가
  `129.121.127.196`을 가리키는지, DNS 전파가 끝났는지 먼저 확인하세요.
- **SSL 발급이 실패해요**: 인증서 발급 전에 반드시 도메인이 그 서버 IP로
  연결되어 있어야 합니다(80번 포트로 실제 응답이 와야 함). DNS 전파가 아직
  안 끝났을 가능성이 높습니다. 몇 분 뒤 스크립트를 다시 실행하면 됩니다
  (이미 만든 리소스는 재사용되어 안전하게 재실행 가능합니다).
- **서버에 이미 다른 사이트가 떠 있어요**: 문제 없습니다. 스크립트는 빈
  포트를 자동으로 찾고, Nginx 설정도 도메인별로 별도 파일을 추가하는
  방식이라 기존 사이트에 영향을 주지 않습니다.
- **비밀번호 보안**: 이 문서 작성 계기가 된 대화에서 서버 root 비밀번호가
  채팅창에 평문으로 공유되었습니다. 배포 작업이 끝나면 `passwd` 명령으로
  root 비밀번호를 새로 변경하는 것을 권장합니다.
