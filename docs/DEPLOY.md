# 외부 서버 배포 가이드 (가장 쉬운 방법)

이 문서는 서버 `129.121.127.196`에 스마트비즈 테마가 적용된 그누보드5
사이트를 배포하는 가장 쉬운 방법을 설명합니다. GitHub 로그인이나 열쇠(SSH
키) 등록 같은 복잡한 과정 없이, **파일 하나 업로드 + 명령어 한 줄**로 끝까지
자동으로 설치됩니다(그누보드5 설치, 테마 적용, 업종 샘플 데이터 채우기,
게시판 생성까지 전부 자동입니다).

## 전체 흐름

```
1. Claude가 준 압축파일을 서버로 업로드 (scp 명령어 한 줄)
2. 서버 SSH 접속 → 압축 풀기 → 배포 스크립트 한 줄 실행
   (여기서 그누보드5 설치 + 테마 적용 + 샘플 데이터까지 전부 자동으로 끝남)
3. 도메인 구매 + A레코드 연결 (직접 하셔야 함)
4. 완료된 사이트 확인
```

---

## 1단계 — 압축파일을 서버로 업로드

**본인 컴퓨터**(서버가 아니라 지금 쓰고 있는 내 컴퓨터)에서 터미널을 엽니다.

- **Windows**: `Windows키` 누르고 `cmd` 입력 → Enter
- **Mac**: `Command+Space` 누르고 `터미널` 입력 → Enter

Claude가 보내드린 `smartbiz-deploy.tar.gz` 파일을 다운로드한 폴더로 이동한
뒤(보통 `Downloads` 폴더), 아래 명령어로 서버에 올립니다. `경로/` 부분은
실제로 파일을 받은 위치로 바꿔주세요 (예: Mac은 `~/Downloads/`,
Windows는 `cd %USERPROFILE%\Downloads` 로 먼저 이동한 뒤 파일 이름만 써도
됩니다).

```bash
scp smartbiz-deploy.tar.gz root@129.121.127.196:/root/
```

- 처음 접속하면 `Are you sure you want to continue connecting (yes/no)?`
  → `yes` 입력 후 Enter.
- 비밀번호를 입력하라고 하면 서버 비밀번호 입력 → **화면에 아무것도 안
  보이는 게 정상**입니다, 그냥 다 입력하고 Enter.
- 업로드가 끝나면(진행률 100% 표시) 다음 단계로 넘어갑니다.

---

## 2단계 — 서버 접속 후 배포 스크립트 실행

같은 터미널에서(또는 새 창에서) 서버에 접속합니다.

```bash
ssh root@129.121.127.196
```

접속되면(프롬프트가 `root@...:~#` 모양으로 바뀝니다), 아래를 순서대로
입력합니다.

```bash
mkdir -p /opt/smartbiz-gnuboard5
tar xzf /root/smartbiz-deploy.tar.gz -C /opt/smartbiz-gnuboard5
cd /opt/smartbiz-gnuboard5
```

이제 배포 스크립트를 실행합니다. **`도메인주소`와 `이메일주소` 부분만 실제
값으로 바꿔서** 입력하세요(도메인을 아직 안 샀다면 일단 임시로 아무 값이나
넣고 실행한 뒤, 3단계에서 도메인을 산 후 **같은 명령어를 다시 한 번**
실행해도 됩니다).

```bash
sudo bash scripts/deploy-server.sh 도메인주소 이메일주소
```

예시:

```bash
sudo bash scripts/deploy-server.sh mysite.example.com myemail@gmail.com
```

- 실행하면 여러 줄의 진행 로그가 쭉 출력됩니다. **몇 분 정도 걸립니다.**
  멈춘 것처럼 보여도 기다려주세요.
- 이 한 번의 실행으로 **전부 자동으로** 처리됩니다:
  - 빈 포트를 자동으로 찾아서 그 포트에만 사이트를 띄움(서버의 다른
    서비스는 안 건드림)
  - Docker, Nginx, Certbot 자동 설치
  - **그누보드5 설치까지 자동** (브라우저에서 설치 화면 클릭할 필요 없음)
  - **스마트비즈 테마 자동 적용**
  - **청소업체(클린프로) 업종 샘플 데이터 자동으로 채워짐** (회사소개,
    서비스 항목 등)
  - 공지사항/온라인문의/포트폴리오/갤러리/고객후기 게시판 자동 생성
  - 도메인 전용 Nginx 설정 추가(기존 설정은 안 건드림)
  - Let's Encrypt 무료 SSL 자동 발급
- 마지막에 이렇게 출력되면 성공입니다:

  ```
  완료! http://도메인주소 (또는 https://도메인주소) 로 접속해보세요.
  관리자 로그인: admin 아무거나16자리비밀번호
  적용된 업종 샘플: cleaning
  ```

  **이 관리자 아이디/비밀번호를 꼭 메모해두세요.** 나중에 관리자로
  로그인해서 회사정보나 사진을 바꿀 때 필요합니다. (같은 정보가 서버의
  `/opt/smartbiz-gnuboard5/.smartbiz_admin_credentials` 파일에도 저장되어
  있습니다.)

> 다른 업종으로 채우고 싶다면 세 번째 값으로 지정할 수 있습니다:
> `staffing`(직업소개소), `outsourcing`(아웃소싱), `labor`(인력사무소),
> `construction`(건설), `cleaning`(청소, 기본값), `autoparts`(자동차부품),
> `generic`(일반회사).
>
> ```bash
> sudo bash scripts/deploy-server.sh mysite.example.com myemail@gmail.com construction
> ```

## 3단계 — 도메인 구매 + A레코드 연결

아직 도메인이 없다면 여기서 구매합니다(2단계 전에 미리 해도 됩니다).

1. [가비아](https://www.gabia.com) 같은 도메인 등록 사이트에서 회원가입/로그인.
2. 원하는 도메인 이름을 검색합니다. `.xyz`, `.shop`, `.site` 같은 TLD는
   첫 해 프로모션으로 1,000원 미만인 경우가 많습니다.
3. 구매 후 **내 도메인 관리 / DNS 관리** 메뉴로 들어갑니다.
4. **A 레코드**를 추가합니다.
   - 호스트(Host): `@` (또는 원하는 서브도메인, 예: `www`)
   - 값(Value): `129.121.127.196`
   - TTL: 기본값 유지
5. 저장 후 몇 분~1시간 정도 기다립니다(DNS 전파, 길면 24시간).
6. 확인: 서버 터미널에서

   ```bash
   dig +short 도메인주소
   ```

   결과로 `129.121.127.196`이 나오면 연결 완료입니다.

7. 만약 2단계를 도메인 없이 먼저 실행했다면, 이제 **2단계의 명령어를 실제
   도메인 주소로 다시 한 번** 실행해주세요. 이미 설치된 부분(그누보드5,
   테마, 샘플 데이터)은 다시 건드리지 않고, 도메인 연결과 SSL 발급만
   새로 진행됩니다.

## 완료 후 — 관리자에서 내용 바꾸기

`https://도메인주소/adm/` 로 접속해 2단계 마지막에 나온 관리자 아이디/
비밀번호로 로그인합니다.

- **환경설정 → 테마 설정**: 테마 적용 상태 확인
- 관리자 메뉴 왼쪽의 **"테마 설정"** 탭: 회사이름, 로고, 대표사진, 전화번호,
  색상 등을 원하는 내용으로 직접 수정
- 같은 탭 안의 **설치 마법사**에서 다른 업종 샘플로 다시 채우거나(단, 이미
  입력된 내용은 자동으로 건너뜁니다), 게시판 상태를 다시 확인할 수 있습니다

## 자주 발생하는 문제

- **`scp`/`ssh` 접속이 안 돼요**: 서버가 켜져 있는지, 비밀번호가 맞는지
  확인하세요. 비밀번호 입력 시 화면에 아무 표시가 없는 건 정상입니다.
- **배포 스크립트 실행 중 에러가 나요**: 어느 단계(`==> N)`)에서 멈췄는지
  화면 로그를 보고 알려주시면 원인을 봐드릴 수 있습니다.
- **도메인 접속이 안 돼요**: `dig +short 도메인주소`로 A레코드가
  `129.121.127.196`을 가리키는지, DNS 전파가 끝났는지 확인하세요.
- **SSL 발급이 실패했다는 메시지가 나와요**: DNS 전파가 아직 안 끝나서인
  경우가 대부분입니다. 몇 분/몇십 분 뒤 2단계 명령어를 다시 실행하면 됩니다
  (재실행해도 안전합니다, 이미 된 부분은 다시 건드리지 않습니다).
- **관리자 비밀번호를 잊어버렸어요**: 서버에서
  `cat /opt/smartbiz-gnuboard5/.smartbiz_admin_credentials` 로 다시 확인할
  수 있습니다.
- **서버에 이미 다른 사이트가 떠 있어요**: 문제 없습니다. 스크립트는 빈
  포트를 자동으로 찾고, Nginx 설정도 도메인별로 별도 파일만 추가하는
  방식이라 기존 사이트에 영향을 주지 않습니다.
- **비밀번호 보안**: 이 문서 작성 계기가 된 대화에서 서버 root 비밀번호가
  채팅창에 그대로 노출됐습니다. 배포가 끝나면 서버에서 `passwd` 명령어로
  root 비밀번호를 새로 변경하는 것을 권장합니다.

## (참고) 이전에 안내했던 git clone 방식

GitHub 저장소에서 직접 코드를 받아오고 싶다면(예: 나중에 최신 버전으로
업데이트할 때) `git clone`으로도 받을 수 있습니다. 이 경우 저장소가
비공개이므로 Deploy key 등록이 필요합니다 — 필요하면 이 방법도 안내해
드릴 수 있으니 말씀해주세요. 처음 배포할 때는 위 1~2단계(파일 업로드
방식)가 훨씬 간단합니다.
