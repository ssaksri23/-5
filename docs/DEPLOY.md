# 외부 서버 배포 가이드 (완전 초보자용, 도메인 + SSL 포함)

이 문서는 컴퓨터 터미널을 처음 써보는 분도 그대로 따라 할 수 있도록, 서버
`129.121.127.196`에 이 저장소(GNUBoard5 + 스마트비즈 테마)를 배포하고, 새로
산 도메인을 연결해 자물쇠(HTTPS/SSL)까지 붙이는 과정을 하나하나 설명합니다.

**중요: 이 작업은 Claude가 대신 실행해주는 게 아니라, 본인이 직접 그 서버에
접속해서 명령어 몇 줄을 입력하는 방식입니다.** 낯설어 보여도 아래 순서대로
복사-붙여넣기만 하면 됩니다.

## 전체 흐름 한눈에 보기

```
0. 터미널(명령어 입력창) 여는 법 확인
1. 서버에 접속 (SSH)
2. GitHub 토큰 발급 (저장소가 비공개라서 필요)
3. 서버로 소스 코드 가져오기 (git clone)
4. 배포 스크립트 한 번 실행 (포트/Docker/Nginx/SSL 전부 자동)
5. 도메인 구매 + A레코드 연결 (가비아 등)
6. 그누보드5 설치 + 테마 적용 (웹 브라우저에서)
```

3~4번은 도메인 DNS가 아직 안 퍼져있어도 미리 해둘 수 있고, 5번은 그 전에
따로 진행해도 됩니다. 순서는 크게 상관없지만, **6번(설치)은 5번(도메인
연결)이 끝난 뒤에** 하는 게 편합니다.

---

## 0단계 — 터미널(명령어 입력창) 여는 법

- **Windows**: 키보드에서 `Windows키`를 누르고 `cmd`라고 입력한 뒤 Enter
  (또는 `PowerShell` 검색). 검은/파란 화면의 명령어 입력창이 뜹니다.
  (Windows 10/11이면 `ssh` 명령어가 기본으로 들어있습니다. 안 되면 대신
  [PuTTY](https://www.putty.org/)를 설치해서 접속하면 됩니다.)
- **Mac**: `Command + Space`를 누르고 `터미널`(Terminal)이라고 입력한 뒤 Enter.

이 창에 아래 나오는 회색 박스 안의 명령어들을 그대로 복사해서 붙여넣고
Enter 치시면 됩니다. (터미널에 붙여넣기는 보통 마우스 오른쪽 클릭 →
붙여넣기, 또는 `Ctrl+Shift+V`, Mac은 `Command+V`)

---

## 1단계 — 서버에 접속하기 (SSH)

터미널에 아래를 입력하고 Enter:

```bash
ssh root@129.121.127.196
```

- 처음 접속하면 `Are you sure you want to continue connecting (yes/no)?`
  라는 질문이 뜹니다 → `yes` 입력 후 Enter.
- `password:` 라고 뜨면 서버 비밀번호를 입력합니다. **입력해도 화면에
  아무것도 안 보이고 커서도 안 움직입니다 — 정상입니다.** 그냥 비밀번호를
  다 입력하고 Enter를 누르세요.
- 접속이 성공하면 프롬프트가 `root@...:~#` 같은 모양으로 바뀝니다. 이제부터
  입력하는 명령어는 내 컴퓨터가 아니라 그 서버에서 실행됩니다.

> ⚠️ 이 서버 비밀번호는 이전에 채팅창에 그대로 노출됐습니다. 아래 작업을
> 다 마친 뒤 서버에서 `passwd` 명령어로 비밀번호를 꼭 새로 바꿔주세요.

---

## 2단계 — 서버 전용 열쇠 만들기 (Deploy key)

이 코드가 들어있는 GitHub 저장소가 비공개(private)라서, 서버가 코드를
받아오려면 "이 서버만" 그 저장소를 읽을 수 있는 열쇠(SSH 키)를 하나
등록해야 합니다. (개인 계정 전체에 접근하는 토큰보다 이 방식이 더
안전해서 이걸로 안내합니다.) **서버 터미널**과 **웹 브라우저**를 번갈아
씁니다.

1. **서버 터미널**(1단계에서 접속한 곳)에 아래를 입력해 열쇠 쌍을
   만듭니다.

   ```bash
   ssh-keygen -t ed25519 -C "smartbiz-deploy" -f ~/.ssh/smartbiz_deploy_key -N ""
   ```

   (몇 가지 질문 없이 바로 만들어집니다.)

2. 방금 만든 **공개키**를 화면에 출력합니다.

   ```bash
   cat ~/.ssh/smartbiz_deploy_key.pub
   ```

   `ssh-ed25519 AAAA...` 로 시작해서 `smartbiz-deploy`로 끝나는 한 줄이
   나옵니다. **이 한 줄 전체를 마우스로 드래그해서 복사**하세요.

3. **웹 브라우저**에서 저장소 페이지로 갑니다:
   `https://github.com/ssaksri23/-5/settings/keys`
   (또는 저장소 → **Settings** → 왼쪽 메뉴 **Security → Deploy keys**,
   방금 스크린샷에 보이던 그 화면입니다.)

4. **Add deploy key** 버튼 클릭.
5. Title(이름)에 아무거나 입력 (예: `배포서버`).
6. Key 입력칸에 2번에서 복사한 공개키 한 줄을 붙여넣기.
7. **Allow write access는 체크하지 않습니다** (읽기 전용이면 충분합니다).
8. **Add key** 클릭.

## 3단계 — 서버로 소스 코드 가져오기

다시 **서버 터미널**로 돌아와서, 먼저 GitHub의 신원 확인 질문에 대비해
접속 테스트를 한 번 합니다.

```bash
ssh -T -i ~/.ssh/smartbiz_deploy_key -o IdentitiesOnly=yes git@github.com
```

`Are you sure you want to continue connecting (yes/no)?` 가 뜨면 `yes`
입력 후 Enter. `Hi ssaksri23/-5! You've successfully authenticated...`
같은 메시지가 뜨면 성공입니다 (에러처럼 보이지만 정상 메시지입니다).

이제 코드를 받아옵니다:

```bash
GIT_SSH_COMMAND="ssh -i ~/.ssh/smartbiz_deploy_key -o IdentitiesOnly=yes" \
  git clone --branch claude/gnuboard5-sellable-theme \
  git@github.com:ssaksri23/-5.git /opt/smartbiz-gnuboard5
```

완료되면 이어서:

```bash
cd /opt/smartbiz-gnuboard5
```

## 4단계 — 배포 스크립트 실행 (자동화)

아래 명령어에서 **`도메인주소`** 와 **`이메일주소`** 부분만 실제 값으로
바꿔서 입력합니다 (도메인을 아직 안 샀다면 5단계를 먼저 하고 와도 됩니다).

```bash
sudo bash scripts/deploy-server.sh 도메인주소 이메일주소
```

예시:

```bash
sudo bash scripts/deploy-server.sh mysite.example.com myemail@gmail.com
```

- 실행하면 여러 줄의 진행 로그가 쭉 출력됩니다(`==> 1) 빈 포트 찾기` 등).
  **몇 분 정도 걸릴 수 있습니다.** 중간에 멈춘 것처럼 보여도 기다려주세요.
- 이 한 번의 실행으로 자동으로 처리되는 것들:
  - 서버에서 **비어있는 포트를 자동으로 찾아** 우리 사이트를 그 포트에만
    띄웁니다(외부에서 그 포트로 직접 접근 불가, 반드시 도메인을 통해서만
    접속됨). 서버에 이미 떠 있는 다른 서비스/포트는 전혀 건드리지 않습니다.
  - Docker, Nginx, Certbot이 없으면 자동 설치.
  - `docker compose up -d --build`로 그누보드5 + 스마트비즈 테마 기동.
  - 지정한 도메인 전용 Nginx 설정 파일을 **새로 추가만** 함(기존 Nginx
    설정은 안 건드림).
  - Let's Encrypt로 무료 SSL 인증서 발급 + HTTPS 자동 전환.
- 마지막에 `완료! https://도메인주소 로 접속해보세요.` 라는 메시지가
  나오면 성공입니다.

> 참고: 아직 도메인의 DNS가 이 서버로 연결되기 전이라면 맨 마지막 SSL 발급
> 단계에서 실패할 수 있습니다. 그럴 땐 5단계(도메인 연결)를 마치고 DNS가
> 퍼진 뒤 **같은 명령어를 다시 한 번 실행**하면 됩니다 — 이미 설치된 부분은
> 다시 건드리지 않고 SSL 발급만 이어서 진행됩니다.

## 5단계 — 도메인 구매 + A레코드 연결

**웹 브라우저**에서 진행합니다.

1. [가비아](https://www.gabia.com) 같은 도메인 등록 사이트에 접속, 회원가입/로그인.
2. 원하는 도메인 이름을 검색합니다. `.xyz`, `.shop`, `.site` 같은 TLD는
   첫 해 프로모션으로 1,000원 미만인 경우가 많습니다. 원하는 이름을 검색해
   보고 저렴한 것으로 구매(결제)합니다.
3. 구매 후 **내 도메인 관리 / DNS 관리** 메뉴로 들어갑니다 (사이트마다 위치가
   조금씩 다르며, 보통 "도메인 관리 → 네임서버/DNS 설정" 같은 이름입니다).
4. **A 레코드**를 새로 추가합니다.
   - 호스트(Host) / 이름: `@` (도메인 자체로 접속하고 싶은 경우) 또는
     `www` 등 원하는 서브도메인
   - 값(Value) / 대상: `129.121.127.196`
   - TTL: 기본값 그대로 두면 됩니다
5. 저장합니다. 보통 몇 분~1시간 정도면 반영되고, 늦으면 최대 24시간까지
   걸릴 수 있습니다(DNS 전파).
6. 서버 터미널(또는 본인 컴퓨터 터미널)에서 아래처럼 확인할 수 있습니다:

   ```bash
   dig +short 도메인주소
   ```

   결과로 `129.121.127.196`이 나오면 연결이 끝난 것입니다.

DNS 연결이 끝났는데 4단계에서 SSL 발급이 실패했었다면, 이제 **4단계
명령어를 다시 한 번 실행**해주세요.

## 6단계 — 그누보드5 설치 + 테마 적용

**웹 브라우저**에서 `https://도메인주소` 로 접속합니다.

1. 처음 배포한 것이라면 자동으로 설치 화면(`/install/`)으로 안내되거나,
   직접 `https://도메인주소/install/` 로 접속해 그누보드5 설치 마법사를
   진행합니다.
   - DB 관련 정보를 물어보면: 호스트 `db`, 포트 `3306`, 나머지 DB이름/
     아이디/비밀번호는 서버의 `/opt/smartbiz-gnuboard5/.env` 파일에서
     확인할 수 있습니다. 서버 터미널에서 아래로 열어볼 수 있습니다:

     ```bash
     cat /opt/smartbiz-gnuboard5/.env
     ```

   - 그 외 사이트명, 관리자 아이디/비밀번호 등은 원하는 값으로 입력하면
     됩니다(이 관리자 계정이 앞으로 사이트를 관리할 계정이니 비밀번호를
     잘 기억해두세요).
2. 설치가 끝나면 방금 만든 관리자 계정으로 로그인합니다.
3. 관리자 화면 상단 메뉴에서 **환경설정 → 테마 설정**으로 들어가 "스마트비즈"
   테마를 선택하고 적용 버튼을 누릅니다.
4. 테마를 적용하면 관리자 메뉴 왼쪽에 새로 **"테마 설정"** 탭이 생깁니다.
   여기서 회사이름/로고/전화번호/색상 등을 입력합니다.
5. 같은 "테마 설정" 탭 안의 **설치 마법사**로 들어가 게시판(공지사항/
   온라인문의/포트폴리오/갤러리/고객후기)을 한 번에 생성합니다. 원하면
   업종별 샘플 데이터(직업소개소, 청소업체 등)도 같이 채워 넣을 수
   있습니다.

여기까지 하면 `https://도메인주소`로 완성된 사이트를 볼 수 있습니다.

## 자주 발생하는 문제

- **`ssh: connect to host ... port 22: Connection refused/timed out`**:
  서버가 꺼져있거나 방화벽 문제일 수 있습니다. 서버 제공업체(호스팅사)
  콘솔에서 서버 상태를 먼저 확인해보세요.
- **비밀번호를 입력해도 반응이 없어요**: SSH/git에서 비밀번호나 토큰을
  입력할 때는 원래 화면에 아무 표시도 안 됩니다(보안 기능). 그냥 끝까지
  입력하고 Enter를 누르면 됩니다.
- **git clone에서 `Permission denied (publickey)` 가 떠요**: 2단계의
  Deploy key가 제대로 등록됐는지, `cat ~/.ssh/smartbiz_deploy_key.pub`로
  나온 내용과 GitHub에 등록한 키가 정확히 같은지 확인하세요. 그리고
  `git clone` 명령어 앞의 `GIT_SSH_COMMAND="ssh -i ~/.ssh/smartbiz_deploy_key ..."`
  부분을 빠뜨리지 않았는지도 확인하세요.
- **도메인 접속이 안 돼요**: `dig +short 도메인주소`로 A레코드가
  `129.121.127.196`을 가리키는지, DNS 전파가 끝났는지 먼저 확인하세요.
- **SSL 발급이 실패해요**: 인증서 발급 전에 반드시 도메인이 그 서버 IP로
  연결되어 있어야 합니다. DNS 전파가 아직 안 끝났을 가능성이 높습니다.
  몇 분/몇십 분 뒤 4단계 명령어를 다시 실행하면 됩니다(재실행해도
  안전합니다).
- **서버에 이미 다른 사이트가 떠 있어요**: 문제 없습니다. 스크립트는 빈
  포트를 자동으로 찾고, Nginx 설정도 도메인별로 별도 파일만 추가하는
  방식이라 기존 사이트에 영향을 주지 않습니다.
- **배포 스크립트를 실수로 두 번 실행했어요**: 안전합니다. 이미 만들어진
  것들은 재사용/갱신만 되고, 기존 게시판 데이터나 회사정보 같은 건 지워지지
  않습니다.
- **비밀번호 보안**: 이 문서 작성 계기가 된 대화에서 서버 root 비밀번호가
  채팅창에 그대로 노출됐습니다. 모든 작업이 끝나면 서버에서 `passwd`
  명령어로 root 비밀번호를 새로 변경하는 것을 권장합니다.
