# 스마트비즈 (SmartBiz) — 그누보드5 다업종 반응형 홈페이지 테마

여러 업종(직업소개소, 아웃소싱업체, 인력사무소, 건설업체, 청소업체, 자동차/폐차부품판매업체,
일반회사)에 문구와 이미지만 바꿔 재사용할 수 있도록 만든 그누보드5(5.6.x) 홈페이지형 테마입니다.

- 코드 수정 없이 관리자 화면에서 회사정보, 로고, 대표이미지, 색상, 메인페이지 섹션
  노출/순서, 배너, 서비스/절차/이유 항목을 관리할 수 있습니다.
- PC/태블릿/모바일 반응형이며, 모바일에서는 햄버거 메뉴와 하단 고정 전화·카카오톡
  상담 버튼을 제공합니다.
- 공지사항/온라인문의/포트폴리오/갤러리/고객후기 게시판 스킨과 FAQ 스킨이 포함되어
  있으며, 설치 마법사가 필요한 게시판과 메뉴를 자동으로 만들어줍니다.
- 온라인문의 게시판은 코어 옵션(`무조건 비밀글`)으로 강제되어, 작성자 본인과
  관리자만 내용을 볼 수 있습니다.
- 7개 업종 샘플 데이터가 포함되어 있어, 설치 마법사에서 업종을 선택하면 회사소개
  문구와 서비스 항목을 바로 채워볼 수 있습니다(이미 입력한 내용은 덮어쓰지 않습니다).

## 설치

자세한 설치 방법은 `docs/install-guide.md` 문서를 참고하세요. 요약하면 다음과 같습니다.

1. `theme/smartbiz/` 폴더를 그누보드5 설치 경로의 `theme/` 폴더 아래에 복사합니다.
2. `adm/` 폴더 안의 파일들을 그누보드5의 `adm/` 폴더에 복사합니다.
3. `extend/` 폴더 안의 파일을 그누보드5의 `extend/` 폴더에 복사합니다.
4. 관리자 페이지 → 환경설정 → 테마 설정에서 "스마트비즈" 테마를 선택·적용합니다.
5. 관리자 메뉴에 새로 생긴 "테마 설정" 탭에서 회사정보를 입력하고, "설치 마법사"에서
   게시판/메뉴를 생성합니다.

이 과정에서 **그누보드5 코어 파일은 전혀 수정하지 않으며, 기존 게시판과 게시글, 회원
데이터는 삭제되거나 덮어써지지 않습니다.**

## 폴더 구성

```
theme/smartbiz/   실제 테마 본체 (그누보드5 theme/ 폴더에 복사)
adm/              관리자 "테마 설정" 화면 파일 (그누보드5 adm/ 폴더에 복사)
extend/           자동 실행 확장 파일 (그누보드5 extend/ 폴더에 복사)
skin/             theme/smartbiz/skin/ 사본 — 미리보기/참고용
install/          theme/smartbiz/install/ 사본 — 미리보기/참고용
sample/           theme/smartbiz/sample/ 사본 — 업종별 샘플 데이터 미리보기/참고용
plugin/           추가 기능을 위해 예약된 빈 폴더 (현재 버전에는 포함된 추가 기능 없음)
docs/             설치설명서
```
