# 스마트비즈(SmartBiz) 테마 설치설명서

## 1. 권장 사양

- PHP 7.4 ~ 8.1 (그누보드5 5.6.x 권장 사양과 동일)
- MySQL 5.7 이상 또는 MariaDB 10.x
- 그누보드5 5.6.x (다른 5.x 버전에서도 대부분 동작하지만, 5.6.x 기준으로
  테스트되었습니다)
- 필수 PHP 확장: gd, mysqli(또는 pdo_mysql), mbstring, zip

## 2. 테마 설치 방법

이미 설치되어 운영 중인 그누보드5 사이트를 기준으로 설명합니다. **아래 과정은
그누보드5 코어 파일을 하나도 수정하지 않으며, 새 파일만 추가합니다.**

1. 패키지 압축을 해제합니다.
2. `theme/smartbiz/` 폴더 전체를 그누보드5 설치 경로의 `theme/` 폴더 아래에
   복사합니다. (최종 경로: `그누보드설치경로/theme/smartbiz/`)
3. `adm/` 폴더 안의 모든 `.php` 파일을 그누보드5의 `adm/` 폴더에 복사합니다.
   (예: `admin.menu950.smartbiz.php`, `theme_admin.lib.php`,
   `theme_company_form.php` 등 총 13개 파일)
4. `extend/smartbiz-theme.extend.php` 파일을 그누보드5의 `extend/` 폴더에
   복사합니다.
5. 파일 소유자/권한을 웹서버 실행 계정(예: `www-data`, `apache`)이 읽을 수
   있도록 맞춰줍니다.
6. 그누보드5 관리자 페이지 → **환경설정 → 테마 설정**으로 이동해 "스마트비즈"
   테마를 선택하고 적용합니다. (테마 목록에 보이지 않으면 3단계 파일 복사
   위치를 다시 확인해주세요.)
7. 테마를 적용하면 관리자 메뉴 좌측에 **"테마 설정"**이라는 새 탭이
   나타납니다. 이 탭이 보이지 않으면 3~4단계가 정상적으로 되었는지,
   최고관리자(super) 계정으로 로그인했는지 확인해주세요.

## 3. 게시판/메뉴 생성 방법 (설치 마법사)

1. 관리자 메뉴 → 테마 설정 → **설치 마법사**로 이동합니다.
2. 현재 설치 상태 표(공지사항/온라인문의/포트폴리오/갤러리/고객후기)를
   확인합니다. "미설치"로 표시된 게시판이 새로 만들어질 게시판입니다.
3. **이미 같은 이름(`bo_table`)의 게시판이 있다면 게시글과 게시판 설정은
   그대로 두고, 스킨 설정만 스마트비즈 테마에 맞게 갱신합니다.** 기존
   데이터가 삭제되거나 덮어써지는 일은 없습니다.
4. (선택) 업종별 샘플 데이터를 채우고 싶다면 "샘플 데이터 적용" 체크박스를
   선택하고 업종을 고른 뒤 실행합니다. 회사정보나 서비스 항목을 이미 입력한
   상태라면 자동으로 건너뛰고 덮어쓰지 않습니다.
5. "게시판 설치/갱신 실행" 버튼을 누르면 게시판과 메인 메뉴가 자동으로
   생성·등록됩니다. 결과 표에서 각 항목이 `created`(새로 생성)인지
   `updated`(스킨만 갱신)인지 확인할 수 있습니다.

온라인문의 게시판은 `무조건 비밀글` 옵션이 적용되어, 작성자 본인과
관리자만 글을 볼 수 있습니다(요청 값을 조작해도 우회할 수 없습니다).

## 4. 관리자 설정 방법

관리자 메뉴 → 테마 설정 아래에 다음 화면들이 있습니다.

- **테마 설정**: 회사명, 로고, 대표이미지, 메인/서브 문구, 대표전화번호,
  이메일, 주소, 카카오톡 상담 링크, 네이버블로그 링크, 메인/보조 색상,
  회사소개, 푸터 사업자정보, SEO 제목/설명
- **섹션 노출순서**: 메인페이지에 표시할 섹션(슬라이드/서비스소개/회사소개/
  이용절차/선택이유/포트폴리오/고객후기/FAQ/온라인문의/오시는길)의 노출
  여부와 순서를 체크박스와 순서 번호로 지정
- **배너 관리**: 메인페이지 배너 이미지 등록/수정/삭제
- **서비스·절차·이유**: 주요 서비스 소개, 이용 절차, "저희를 선택해야 하는
  이유" 3개 섹션의 항목을 각각 등록/수정/삭제
- **설치 마법사**: 위 3번 항목 참고
- **라이선스 정보**: 구매자명, 허용 도메인, 구매일, 설치 가능 사이트 수,
  기술지원 종료일 등록/확인. **이 화면의 안내는 참고용이며, 어떤 경우에도
  사이트 기능이나 데이터에 영향을 주지 않습니다.**

팝업 공지는 그누보드5 코어 기능인 **팝업레이어관리**(환경설정 근처 메뉴)를
그대로 사용합니다. 별도의 팝업 관리 화면은 테마에 포함되어 있지 않습니다.

## 5. 권장 이미지 사이즈

| 용도 | 권장 크기 | 비고 |
| --- | --- | --- |
| 로고 | 가로 240px 내외, 투명 배경 PNG 권장 | 헤더에 원본 비율로 표시 |
| 대표이미지(히어로) | 1920×800px | 가로로 넓은 이미지 권장 |
| 배너 이미지 | 1200×400px | 위치(상단/하단)에 따라 비율 유지 |
| 포트폴리오·갤러리 첨부 | 1600px 이하, 5MB 이하 | jpg/jpeg/png/gif/webp만 허용 |

업로드 용량 제한은 게시판별로 1MB(일반 게시판) ~ 5MB(포트폴리오/갤러리)로
설정되어 있으며, 필요 시 그누보드5 게시판 관리에서 조정할 수 있습니다.

## 6. 문제 해결 체크리스트

- **테마 목록에 스마트비즈가 안 보여요**: `theme/smartbiz/index.php`,
  `head.php`, `tail.php`, `theme.config.php`, `readme.txt`가 모두 복사되었는지
  확인하세요.
- **테마는 적용됐는데 "테마 설정" 관리자 메뉴가 안 보여요**: `adm/` 폴더에
  `admin.menu950.smartbiz.php`를 포함한 13개 파일이 모두 복사되었는지,
  최고관리자(super) 등급 계정으로 로그인했는지 확인하세요.
- **회사정보를 저장했는데 메인페이지에 반영되지 않아요**: `extend/`
  폴더에 `smartbiz-theme.extend.php`가 복사되어 있는지 확인하세요. 이
  파일이 없으면 테마 전용 데이터베이스 테이블이 자동으로 만들어지지 않습니다.
- **게시판 글쓰기에서 "올바른 방법으로 이용해 주십시오" 오류가 나요**:
  브라우저 뒤로가기로 재전송하지 말고 글쓰기 페이지를 새로 열어서
  작성해주세요(그누보드5의 글쓰기 CSRF 토큰은 1회용입니다).
- **업로드한 이미지가 게시글에 안 보여요**: 이미지 확장자(jpg/jpeg/png/gif/
  webp)와 5MB 용량 제한을 확인하세요.
- **모바일에서 레이아웃이 깨져요**: 브라우저 캐시를 비우고 새로고침해보세요.
  이 테마는 별도의 모바일 스킨 없이 CSS로만 반응형을 구현합니다.
- **라이선스 화면에 "도메인이 다릅니다" 안내가 떠요**: 실제 서비스 도메인을
  라이선스 정보의 "허용 도메인"에 등록해주세요. 이 안내는 참고용이며 사이트
  이용에는 영향이 없습니다.

## 7. 업데이트 방법

1. 새 버전 패키지를 받으면 먼저 `CHANGELOG.md`에서 변경 내용을 확인하세요.
2. `theme/smartbiz/`, `adm/`의 `theme_*.php`·`admin.menu950.smartbiz.php`,
   `extend/smartbiz-theme.extend.php` 파일을 새 버전 파일로 교체합니다.
3. 관리자 화면에서 직접 입력한 회사정보/섹션/배너/서비스 데이터는 별도의
   데이터베이스 테이블에 저장되어 있어 파일을 교체해도 그대로 유지됩니다.
4. 업데이트 후 관리자 메뉴 → 테마 설정 → 설치 마법사를 한 번 더 실행해
   게시판 스킨 설정이 최신 상태인지 확인하는 것을 권장합니다(기존 게시글은
   보존됩니다).

## 8. 라이선스 및 사용 범위

이 테마의 사용 범위, 재배포 금지 사항, 기술지원 조건은 패키지에 포함된
`LICENSE.txt`를 확인해주세요. 라이선스 정보는 관리자 화면의 "라이선스 정보"
메뉴에서 확인·입력할 수 있으며, 확인 실패 시에도 사이트 기능은 절대
차단되지 않습니다.
